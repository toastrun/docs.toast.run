A target falls back to the target language home page when the exact page is missing. A row is omitted entirely when no link target exists. {%- endcomment -%} {%- assign languages = site.data.languages -%} {%- assign versions = site.data.versions -%} {%- assign all_urls = site.pages | if all_urls contains lang_fallback -%} {%- assign lang_target = lang_fallback -%} {%- endif -%} {%- endunless -%} {%- if lang_target -%} {%- assign lang_has_links = true -%} {{ lang.label }} {%- endif
